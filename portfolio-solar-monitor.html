Solar Monitoring Systems With Alarm Systems

Custom PCB design for solar panel monitoring with integrated alarm systems — tracking voltage, current, temperature, and detecting faults in real-time.

Platform ESP32 DevKit
Design Tool KiCAD / Proteus
Interface Blynk 2.0 & OLED
Type Personal Project
01 — Context

Why Monitor Solar Panels?

As a passionate advocate for clean energy, I embarked on a personal project to create a DIY Solar Monitoring System. Solar panels are a significant investment, and their performance can degrade due to various factors — shading, dust accumulation, temperature changes, or electrical faults. Without monitoring, these issues often go unnoticed until they significantly impact energy production.

This system is designed to ensure my solar PV setup operates efficiently, providing insights into critical parameters such as voltage, current, temperature, power, and energy. More importantly, it includes an intelligent alarm system that alerts me when performance drops below expected levels, enabling proactive maintenance.

My aim is to share a cost-effective and insightful solution for monitoring solar PV systems. By building this project, I gained a deeper understanding of the workings of my solar setup and could customize it to meet my specific needs — all accessible from my smartphone in real-time.

02 — Hardware Design

PCB Design & Sensor Integration

The hardware design centers around the ESP32 microcontroller, chosen for its built-in Wi-Fi capabilities and adequate analog-to-digital conversion support. The circuit was designed to safely measure high voltages from the solar panel while protecting the sensitive electronics.

Key Components

  • ESP32 DevKit — Central processing unit with Wi-Fi connectivity for data transmission
  • ACS712 Current Sensor — Hall-effect sensor measuring up to 30A with electrical isolation
  • Voltage Divider Circuit — Precision resistor network (100K/10K) for safe voltage measurement
  • DS18B20 Temperature Sensor — Digital temperature monitoring with OneWire protocol
  • BH1750 Light Sensor — Measures ambient light intensity in lux for irradiance calculation
  • ADS1115 ADC — 16-bit analog-to-digital converter for precise sensor readings
  • XL7015 Buck Converter — Steps down solar panel voltage to regulated 5V for components
03 — Alarm System

Intelligent Fault Detection

The alarm system is what makes this project truly useful. By comparing actual power output against expected power (calculated from irradiance and temperature data), the system can detect when the panel isn't performing as it should.

Threshold Detection Logic

The system calculates expected power using the formula: Pout = Pstc × fg × ftemp × nCable, where Pstc is the panel's rated power, fg is the irradiance factor, ftemp accounts for temperature derating, and nCable represents cable efficiency. The power ratio (measured/expected) indicates system health.

  • Power Ratio < 0.9 — Triggers "Potential Shading" alert via Blynk notification
  • Power Ratio > 1.3 — Triggers "Maintenance Needed" alert for potential faults
  • Real-time Notifications — Instant alerts sent to mobile device through Blynk cloud

04 — Implementation

Assembly & Calibration

Building the system involved careful soldering, calibration of sensors, and extensive testing. Each component was verified individually before integration to ensure accurate readings.

Assembly Process

First, the buck converter was connected to the solar panel and adjusted to output a stable 5V. Then, the voltage divider was calibrated using a multimeter to ensure accurate voltage scaling. The current sensor was zero-calibrated to account for any offset. Finally, all components were connected according to the schematic and housed in a protective enclosure.

Key Calculations

Voltage Measurement: Vin = Raw Voltage × (R1 + R2) / R2, where R1 = 100KΩ and R2 = 10KΩ

Current Measurement: Current (A) = (ADC Voltage - Offset) / Sensitivity, with offset at 2.5V and sensitivity at 40 mV/A

Lux to Irradiance: Using the conversion factor 116 lux = 1 W/m² based on research findings

05 — Software

Firmware & Cloud Integration

The firmware was written in Arduino C++ and handles sensor polling, calculations, display updates, and cloud communication. The ESP32 connects to Wi-Fi and transmits data to the Blynk cloud platform, enabling remote monitoring from anywhere.

Key Libraries Used

  • BlynkSimpleEsp32 — Cloud connectivity and notification handling
  • Adafruit_ADS1X15 — ADC interface for precise analog readings
  • DallasTemperature — Temperature sensor communication
  • Adafruit_SSD1306 — OLED display driver
  • BH1750 — Light sensor interface

06 — Results

A Working Monitoring System

The completed system successfully monitors solar panel performance in real-time, providing accurate readings for voltage, current, power, energy, temperature, and irradiance. The alarm system correctly identifies performance anomalies and sends notifications to my phone.

System Capabilities

  • Real-time monitoring of voltage, current, power, and energy production
  • Temperature compensation for accurate power estimation
  • Light intensity measurement converted to solar irradiance
  • Expected power calculation with performance ratio analysis
  • Automated fault detection with Blynk notifications
  • Cost savings tracking based on energy generated
