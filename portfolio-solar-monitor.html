SOLAR MONITORING PROJECT


1. Introduction



1.1 Overview


As a passionate advocate for clean energy, I embarked on a personal project to create a DIY Solar Monitoring System. This system is designed to ensure my solar PV setup operates efficiently, providing insights into critical parameters such as voltage, current, temperature, power, and energy.



1.2 Project Goals


My aim is to share a cost-effective and insightful solution for monitoring solar PV systems. By building this project, I gained a deeper understanding of the workings of my solar setup and could customize it to meet my specific needs.

2. Why Solar Panel Monitoring?



Benefits


Measure solar production and track crucial parameters in real-time, all accessible from my smartphone.

3. System Components



3.1 ESP32 DevKit


The microcontroller serves as the central processing unit, gathering data from sensors, performing calculations, and controlling the OLED display.



3.2 ACS712 Current Sensor


The ACS712 measures the current flowing through the solar panel by converting the magnetic field generated by the current into a proportional output voltage. ESP32 MCU reads this voltage and converts it into the actual current value.



3.3 Voltage Divider Circuit


The voltage divider, composed of two resistors in series, is connected to the solar panel’s positive terminal and GND. The junction between the two resistors provides a scaled-down voltage, which the ESP32 MCU reads and converts back to the actual voltage value. This method allows the circuit to measure voltages higher than the MCU’s maximum analog input voltage.



3.4 DS18B20 Temperature Sensor


This digital temperature sensor measures the temperature of the solar panel or other system components. It communicates with the XIAO ESP32 MCU using the OneWire protocol, providing accurate temperature readings that can help identify performance issues related to temperature



3.5 Optional: OLED Display


The OLED display is used to visualize the collected data in real time. It communicates with the ESP32 MCU using the I2C protocol, allowing you to easily display voltage, current, temperature, power, and energy readings.



3. Light Sensor


To monitor the brightness of the sunlight and make sure it is allign with the power production from the solar panel.

6. How It Works



6.0 Regulating Voltage Input Of The Monitoring Components


First, a buck converter is employed to regulate the voltage input from the solar panel, ensuring it remains below 5V to prevent damage to components like the ESP32. The buck converter steps down the higher solar voltage to a constant 5V output.


Buck Converter XL7015


6.1 Measuring Voltage


To measure the voltage, a voltage divider is utilized. This enables precise monitoring of the solar panel's voltage, providing essential data for the overall system.


Voltage Divider


6.2 Measuring Current


Utilizing an ACS712 Hall-Effect Current Sensor, this measures the flow of current from the solar panel. The sensor has a maximum capacity of 30 Amps, ensuring accurate current readings.



Current Sensor ACS712


6.3 Measuring Temperature


The DS18B20 temperature sensor is employed to measure the temperature of the solar panel. Accurate temperature data aids in understanding the panel's operating conditions.



DSB18B20


6.4 Measuring Light Surroundings


The BH1750 light sensor is used to measure light intensity in lumens. This information is crucial for determining the irradiation level, providing insights into the solar panel's exposure to light.



BH1750


6.5 Converting Analog Signal To Digital Signal


Some of the data gain by some of the sensor is in analog. So, an ADS1115 Analog-to-Digital Converter is utilized. This ensures compatibility with the ESP32, which reads data more effectively in digital form.



Analog to Digital Converter


6.6 Data Transmitted To The ESP32 Microcontroller


Data collected from various sensors is transmitted to the ESP32 microcontroller for processing and analysis.



ESP32


6.7 Comparing Lumens Into Irradiation


Conversion of lumens to irradiation involves referencing a specific research paper for conversion values as there is no universal conversion ratio. Here is the link of the research paper and below is their findings.



Conversion from Brightness Lux to irradiance


There are few range of number you can choose from. In my case I choose 116lx=1Wm-2

Data is displayed locally on an OLED display, providing real-time information about the solar panel's performance.

8. Calculations

8.1 Measuring Voltage


Vout = R2/(R1+R2) x Vin

Vin = (R1+R2)/R2 x Vout

The ads.readADC_SingleEnded(0) function reads the raw analog data

We’re going to read the output value with one of the analog inputs of ESP32 and its analogRead() function. That function outputs a value between 0 and 4095 that is 3.3/4095 for each increment

Vin = Raw Voltage *(R1+R2)/R2 ; R1=100k and R2=10k

8.2 Measuring Current


analog read value = analogRead(Pin);

ADCVoltage = ads.readADC_SingleEnded(1);

Then multiply the default gain of ADC1115 (0.1875/1000) and then multiply the voltage divider factor ( R3+R4)/R3

Current in amp = ( ADCVoltage – Offset Voltage ) / sensitivity

As per data sheets offset voltage is Vcc/2 ( 2.5V ) and sensitivity is 40 mV/A


8.3 Expected Power


Pout= Solar Power Ratings x fg x ftemp x nCable

Solar Power Ratings = 12W

Irradiance factor,fg = G/1000

Temperature factor,ftemp = 1 + [(Power Temperature Coeficient/100%) x (Measured Temperature - 25)

Cable efficiency, nCable = 0.97 (Standard)

8.4 Power Ratio


Power Measured (Voltage Measured x Current Measured) / Expected Power


9. Software and Libraries

Highlight code with copy button 
                          
                            #define BLYNK_TEMPLATE_ID "TMPL637DiLTro"
                            #define BLYNK_TEMPLATE_NAME "Solar Monitoring Project"
                            #define BLYNK_AUTH_TOKEN "qGSDQvhX8txknRJ-XC9VqSV9mVO4aBNc"
                            #define BLYNK_PRINT Serial
                            
                            #include <Wire.h>
                            #include <Adafruit_SSD1306.h>
                            #include <Adafruit_ADS1X15.h>
                            #include <BlynkSimpleEsp32.h>
                            #include <OneWire.h>
                            #include <DallasTemperature.h>
                            #include <BH1750.h>
                            
                            // Pin definitions
                            const int oneWirePin = 13; // Replace with the appropriate GPIO number for your DS18B20
                            
                            // OLED display
                            Adafruit_SSD1306 display(128, 64, &Wire);
                            
                            // ADS1115
                            Adafruit_ADS1115 ads;
                            
                            // DS18B20 temperature sensor
                            OneWire oneWire(oneWirePin);
                            DallasTemperature sensors(&oneWire);
                            
                            // BH1750 light sensor
                            BH1750 lightMeter;
                            
                            float voltagee = 0;
                            float current = 0;
                            float power = 0;
                            unsigned long previousMillis = 0;
                            float energy = 0;
                            float temperature = 0;
                            float saving = 0; // cost saving
                            float lux = 0;     // light level
                            float irradiance = 0; // converted irradiance
                            float expectedPower = 0; // expected power output
                            float powerRatio = 0;    // ratio of measured power to expected power
                            const float EnergyCost = 6.5;
                            
                            // Voltage divider resistor values
                            const float R1 = 100; // 100K
                            const float R2 = 10;  // 10K
                            const float R3 = 1;   // 1K
                            const float R4 = 2;   // 2K
                            
                            // ACS758 zero-current output voltage (Offset Voltage)
                            float OffsetVoltage = 2.5;
                            // ACS758 current sensor sensitivity
                            const float sensitivity = 40; // in mV/A
                            
                            // Expected power output parameters
                            const float Pstc = 12.0; // W
                            const float fmm = 1.0;
                            const float fg_coefficient = 1.0 / 1000.0;
                            const float fage = 1.0;
                            const float cableEfficiency = 0.97;
                            
                            //========================= Variables for wifi server setup =============================
                            const char *ssid = "Durrani";
                            const char *password = "87654321";
                            const char *blynkAuth = "qGSDQvhX8txknRJ-XC9VqSV9mVO4aBNc";
                            
                            float luxToIrradiance(float lux)
                            {
                              // Conversion factor: 116 lux = 1 W/m²
                              return lux / 116.0;
                            }
                            
                            void setup()
                            {
                              Serial.begin(115200);
                              // Initialize the Wi-Fi and Blynk connections
                              WiFi.begin(ssid, password);
                              while (WiFi.status() != WL_CONNECTED)
                              {
                                delay(500);
                                Serial.print(".");
                              }
                              Serial.println("\nConnected to Wi-Fi");
                              Blynk.begin(blynkAuth, ssid, password);
                            
                              // Initialize the OLED display
                              display.begin(SSD1306_SWITCHCAPVCC, 0x3C);
                              display.clearDisplay();
                              display.display();
                            
                              // Initialize the ADS1115
                              ads.begin();
                            
                              // Initialize the DS18B20 temperature sensor
                              sensors.begin();
                            
                              // Initialize the I2C bus for BH1750
                              Wire.begin(33,32);
                            
                              // Initialize BH1750
                              lightMeter.begin(BH1750::CONTINUOUS_HIGH_RES_MODE, 0x23, &Wire);
                            }
                            
                            void loop()
                            {
                              // Read the raw voltage values from the ADS1115
                              int16_t voltageRaw = ads.readADC_SingleEnded(0);
                              int16_t currentRaw = ads.readADC_SingleEnded(1);
                            
                              // Calculate the voltage values in Volts
                              float voltageVolts = voltageRaw * (0.1875 / 1000); //  0.1875mV is default Gain
                              float voltagee = (voltageVolts * ((R1 + R2) / R2));     // Calculate the actual voltage by using the voltage dividers
                            
                              // Calculate the current values in Amps
                              float currentVolts = currentRaw * ((R3 + R4) / R4) * (0.1875 / 1000); //  0.1875mV is default Gain
                              current = (currentVolts - OffsetVoltage )/(sensitivity / 1000.0) ;     // convert voltage into current
                            
                              // Calculate the power output (P = V * I)
                              power = voltagee * current;
                            
                              // Calculate energy by integrating power over time
                              unsigned long currentMillis = millis();
                              energy += (power) * (currentMillis - previousMillis) / 3600000; // Energy in Wh
                              saving = EnergyCost * (energy / 1000);
                              previousMillis = currentMillis;
                            
                              // Read the temperature from the DS18B20 sensor
                              sensors.requestTemperatures();
                              temperature = sensors.getTempCByIndex(0); // temperature in Celsius
                              //temperature = sensors.getTempFByIndex(0); // temperature in Fahrenheit
                            
                              // Read light level from BH1750
                              lightMeter.configure(BH1750::CONTINUOUS_HIGH_RES_MODE);
                              lux = lightMeter.readLightLevel();
                              Serial.print("Light: ");
                              Serial.print(lux);
                              Serial.println(" lx");
                            
                              // Convert lux to irradiance in W/m²
                              irradiance = luxToIrradiance(lux);
                              Serial.print("Irradiance: ");
                              Serial.print(irradiance);
                              Serial.println(" W/m²");
                            
                              // Calculate expected power output
                              float fg = irradiance * fg_coefficient;
                              float ftemp = 1.0 + ((-0.45/100) * (temperature - 25));
                              expectedPower = Pstc * fmm * fg * ftemp * fage * cableEfficiency;
                            
                              // Calculate the ratio of expected power to measured power
                              if (power != 0)
                              {
                                powerRatio = power / expectedPower;
                            
                                // Check if the ratio is below 0.9
                                if (powerRatio < 0.9)
                                {
                                  // Send notification to Blynk app via email
                                  Blynk.logEvent("Potential shadding: Power ratio is below 0.9! Solar panel might shadded");
                            
                                }
                                // Check if the ratio is higher than 1.3
                                else if (powerRatio > 1.3)
                                {
                                  // Send notification to Blynk app via email
                                  Blynk.logEvent("Maintenance needed: Power ratio is out of range!");
                            
                                }
                              }
                              else
                              {
                                powerRatio = 0; // Avoid division by zero
                              }
                            
                              // ================= Display Data on Blynk App ================================================
                              Blynk.run();
                              Blynk.virtualWrite(V0, voltagee);
                              Blynk.virtualWrite(V1, current);
                              Blynk.virtualWrite(V2, power);
                              Blynk.virtualWrite(V3, energy);
                              Blynk.virtualWrite(V4, temperature);
                              Blynk.virtualWrite(V5, saving);
                              Blynk.virtualWrite(V6, lux);
                              Blynk.virtualWrite(V7, irradiance);
                              Blynk.virtualWrite(V8, expectedPower);
                              Blynk.virtualWrite(V9, powerRatio);
                            
                              // Display the values on the OLED screen
                              display.clearDisplay();
                              display.setTextSize(1);
                              display.setTextColor(WHITE);
                              display.setCursor(10, 10);
                              display.print("V: ");
                              display.print(voltagee, 2);
                              display.setCursor(70, 10);
                              display.print("A: ");
                              display.print(current, 2);
                              display.setTextSize(2);
                              display.setCursor(10, 25);
                              display.print("P: ");
                              display.print(power, 2);
                              display.setCursor(10, 45);
                              display.print("E: ");
                              display.print(energy, 2);
                              display.display();
                            
                              delay(100);
                            }
